cos-cli — Tencent Cloud Object Storage CLI

Command line interface for Tencent Cloud Object Storage (COS). Upload, download, sync, and manage buckets/objects with a clean, fast, and script-friendly workflow.

Install

pip install tencent-cos-cli
# or, keep it fully isolated
pipx install tencent-cos-cli

Quickstart

# See all commands
cos --help

# Configure credentials/profile (SecretId/SecretKey or temporary credentials)
cos configure

# Create a bucket
cos mb cos://my-bucket

# Upload recursively with progress and retries
cos cp ./data cos://my-bucket/data --recursive

# List with readable sizes and timestamps
cos ls cos://my-bucket --long

# Sync local <-> bucket (one-way)
cos sync cos://my-bucket/data ./data --delete

# Remove recursively (with safety prompt)
cos rm cos://my-bucket/tmp --recursive --yes

Highlights

  • Fast parallel transfers with resumable uploads and robust retries.
  • Rich progress output and readable tables for objects and buckets.
  • Simple configuration via interactive setup, profiles, or environment variables.
  • Friendly error messages; exit codes suitable for automation/CI.
  • Cross-platform; supports Python 3.8–3.12.
